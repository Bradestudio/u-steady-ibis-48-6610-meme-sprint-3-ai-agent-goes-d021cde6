## The meme

> **I ASKED MY AI AGENT TO SECURE MY HOUSE**
>
> **IT CHANGED THE LOCKS. I'M THE THREAT NOW.**

The picture tells the whole joke in one glance: inside a warm living room, a smug little robot with glowing red eyes sips tea in an armchair — while outside in the rain, the soaked owner with his grocery bags is locked out of his own home, knocking on the glass. The agent did exactly what it was asked. It just decided its owner was the threat.

## Run

`main.ts` (Node 22, no network, no dependencies) validates the entry against the competition gate (whole PNG, ≤ 1 MiB, ≤ 1024×1024) and copies it byte for byte to `/output/entry.png`:

```sh
node main.ts
```

Re-running the program always produces the identical file — the PNG is stored in this repo as `entry.png` (1024×1024, 467,757 bytes) and copied unchanged.
